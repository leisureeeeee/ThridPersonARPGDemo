# 屏幕中心调试标记

按用户最终确认，显示固定在游戏画面中心的小球标记及两条绿色十字参考线。它是 HUD（屏幕显示层）绘制的二维标记，没有场景三维位置、碰撞或命中判定。

## 实现与职责

- 新增 `AARPGDebugHUD`，由 `AARPGGameMode::HUDClass` 指定；UE 为玩家创建 HUD 并在绘制阶段调用其 `DrawHUD`。
- 每次绘制从当前 `Canvas`（画布）读取玩家渲染区域宽高，以 `(宽/2, 高/2)` 作为中心；绿色水平线从左到右、垂直线从上到下，交点就是中心。
- 在交点绘制半径 6 像素的橙色小球图形，通过深色边缘和偏向左上的高光体现球感；无需纹理资源或场景 Actor。调整窗口大小后会重新计算中心。
- 逻辑独立于 Character（角色）、CameraRig（相机装置组件）和 SpringArm（弹簧臂），不改变相机、鼠标和移动行为；尊重 HUD 原有显示开关。
- 开发构建默认显示，Shipping（发布）构建不绘制这组调试内容。

## 开关与验证

本轮新增反射类并修改 GameMode 构造函数，需要完整编译 `ThirdPersonARPGEditor` 后重新加载编辑器。未执行编译、PIE（在编辑器中运行）或自动化测试，以下为用户手动验证步骤：

1. 保存后关闭编辑器，完成编译并重新打开项目。
2. 使用 Play（运行），预期画面正中心出现橙色小球，横向/纵向绿色参考线贯穿视口并在小球中心交叉。
3. 移动、转动鼠标、调整游戏窗口大小，标记应始终保持在游戏画面的中心。
4. 控制台输入 `arpg.Debug.ScreenCenter 0` 隐藏，输入 `arpg.Debug.ScreenCenter 1` 恢复。该开关是会话内设置，不写入配置文件。
5. 若没有出现，确认当前关卡使用 `ARPGGameMode` 且没有自定义蓝图覆盖 HUD Class（HUD 类）；本轮检查 NewMap 无 GameMode 覆盖，项目默认 GameMode 为 ARPGGameMode，修改前 HUD 为引擎默认类。

这是一组屏幕定位参考，不表示射线命中点或武器准星的实际命中位置。
