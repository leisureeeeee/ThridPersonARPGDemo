# 方向起步与转身同步

实现日期：2026-10-21。保留已确认正常的起停姿势保留、惯性化和松键收脚节奏。

## 资产检查与选用

本轮实际检查普通前向、左90、右90、后180四段 Start。root 轨道没有旋转。左右90的身体骨骼确实改变朝向；B_180 的身体方向接近前向基准，主要是后退起步，不能直接当作180转身使用。

使用 AS_Walk_Start_F_L_90_Seq 和 AS_Walk_Start_F_R_90_Seq，分别生成76/86个采样点。骨盆相对前向基准的终端朝向约为 -86.4348°/+86.0223°。两段新增启用 ForceRootLock、关闭 EnableRootMotion；其他动画和当前停步设置不变。

180°使用左右转身起步的角度适配，是近似版，不是新增了原生180°脚步动画。大幅适配仍可能滑脚，不能宣称达到动作捕捉专用转身的效果。

## 配置与时钟

新增 UARPGDirectionalStartSet 数据资产和 FARPGDirectionalStartProfile，保存动画引用、原始身体转角和每帧的时间/水平距离/身体转角。实例为 /Game/BP/MyCharatcer/DA_DirectionalStarts，由 BP_Character 的移动组件默认配置引用。C++ 不硬编码 Katana 资产路径。

骨盆欧拉角接近90°俯仰，直接读取 yaw 会跳变。因此采样脚本使用四元数旋转水平轴，与同归一化时刻的前向 Start 姿势比较，再展开连续角度；并不是把文件名中的90或180写成假曲线。Content/Python/bake_directional_starts.py 可重新生成单个 profile。

移动组件统一推进动画时间：依据实际移动距离选时刻，同时为站定转身前导保留最低0.6倍时间推进、最高1.5倍，防止尚未平移时锁在首帧。旋转进度来自该时刻的身体转角比例，只向前推进。Actor朝向按本次目标转角同步，动画实例读取完全相同的动画和时间。

## 状态与输出

- 静止或低速重新输入，当前朝向与目标夹角 >=45°：选择最接近的左右转身起步。
- 普通行走90°拐弯：维持原行走，不强制打断。
- 行走中大角度反向：先按原逻辑制动，降到转身速度阈值后进入方向起步，替代原来的纯程序低速旋转。
- 接近180°时选择动画已有的转身侧，必要时用等效长角度到达目标，避免把左转脚步反向播放。
- 松键取消方向选择，进入原停步；中途意图偏离锁定方向超过50°时结束当前起步选择，交回普通移动/后续掉头逻辑，保证输入响应。
- 起步完成后交回 Walk；退出姿势保留到下次进入，不提前清零。

Start 的序列评估器现同时接 ActiveStartAnimation 和 StartAnimationTime。主输出为：locomotion → Rotate Root Bone（旋转根骨骼）→ Inertialization（惯性化）→ 输出姿势。StartRootYawOffset 抵消动画内部相对前向的身体旋转，避免 Actor旋转与身体动画叠加成双重旋转；完成或打断时由惯性化衔接回普通姿势。

## 配置写入与旧实例

通过编辑器 ObjectTools 属性接口配置蓝图默认值，未绕过 Python 对类默认对象修改的限制。旧关卡实例保留空的 defaults-only 配置，实例属性重置接口不能编辑该字段，因此新增移动组件 OnRegister：若该实例配置为空，则只读角色蓝图默认移动组件，并继承其配置。没有直接从 Python 修改类默认对象，没有为此保存用户地图。

BP_Character 原本未跟踪，本轮为保存必要配置纳入 LFS；其已有组件/相机等内容保留，修改前副本保存在工作区 .ue-directional。没有重写用户其他源码或资产。

## 掉头时头部保持旧方向的修正（2026-10-21）

用户确认普通走路、未播放拔刀时也出现。静态采样发现，左右方向起步的骨盆和头部并非一起转向：相对同归一化时刻的前向起步，左转末尾骨盆约-86.43度、头部约-17度；右转末尾骨盆约86.02度、头部约-0.47度。现有根旋转补偿按骨盆消除动画内转向，会把这种头身差保留下来；90度动画适配180度时更明显。这是数据层面的明确证据，未运行关卡复现以排除所有其他因素。

保留原始Katana资产，新增项目内AS_Walk_Start_L90_HeadAligned与AS_Walk_Start_R90_HeadAligned派生序列。Content/Python/bake_directional_head_alignment.py逐原始采样帧计算头部与骨盆相对前向基准的水平朝向差，把相应世界竖直轴旋转乘到头部组件空间四元数，再用neck_01父变换逆转换回局部头骨旋转，写入派生片段。保留前向基准原有头部动作，不使用不稳定的骨盆直接欧拉Yaw；只改变head的局部旋转，不修改骨盆、脊柱、腿、根运动或其他骨骼局部轨道。

生成左76/右86帧，最大补偿约69.43/86.50度。两片段采样的头部相对转角与骨盆一致，例如右0.6归一化时刻均约80.74度；原数据头部约-0.5度。全帧资产完整性比对：所有骨骼局部平移/缩放差为0，除head以外局部旋转最大数值误差约0.0000035度；时长1.25/1.416667秒、根锁和骨架保持。

DA_DirectionalStarts仅替换两个Animation引用，AuthoredYaw和76/86点MotionSamples未变，因此C++的距离时钟、Actor转身和根补偿继续使用原配置。这会同时影响用这两段起步的90度与180度转向，不修改全局头部跟随、镜头或拔刀分层。源Katana动画和普通Walk循环保持。
