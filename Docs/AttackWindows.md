# 轻攻击动作帧与挥刀轨迹

## 本版时序

当前 AM_LightAttack 使用60 FPS（每秒60帧）、从0开始计帧。原动画长约1.4167秒，对应85帧间隔。

| 动作范围 | 行为 |
| --- | --- |
| 0–8帧 | 前摇，不能取消 |
| 9–16帧 | 命中窗口，开启刀刃接触诊断 |
| 17–23帧 | 强制后摇 |
| 24帧起 | 空格可以取消攻击并躲避 |
| 36帧起 | 有移动输入时取消攻击、混出蒙太奇并恢复移动 |

没有后续输入时完整收势。躲避输入缓冲0.10秒：例如在窗口前约0.08秒按下，窗口开放时消费一次；更早的输入会过期。只缓存一次方向，不缓存下一刀。没有加入无敌帧、连招、体力或伤害。

## 在哪里调整

打开 `/Game/BP/MyCharatcer/Animations/LightAttack/AM_LightAttack`，Notify（通知）中有三条轨道：AttackHit、CancelEvade、CancelMove。各轨道放置原生 Attack Window（攻击窗口）AnimNotifyState（动画通知状态），分别选择 Hit、EvadeCancel、MoveCancel。拖动范围即可调整窗口，无需修改Character（角色）或重新编译。

默认范围是 `[9/60,17/60)`、`[24/60,动画末尾)` 和 `[36/60,动画末尾)`。改变播放倍率会随动画一起缩放窗口；HUD（抬头显示）的帧数和时间条读取实际蒙太奇，不另外运行一套帧计时器。

此通知类原生启用Branching Point（分支点）模式，窗口在蒙太奇时间跨过边界时同步更新；避免后台低帧率下Queued（队列）通知延后一帧，导致HUD显示的窗口与当前动画时间不一致。

CancelEvade的结束点在动画末尾前1毫秒，CancelMove在末尾结束，用于避开引擎“同一时刻多个分支点只触发一个”的限制；正常结束时技能仍统一兜底清理所有窗口。调窗口时也应避免分支点端点完全重合。

## 调试画面

Alt拔刀，左键挥刀。左上角显示当前动画帧、HIT/EVADE/MOVE三个窗口、有效采样数与Contacts（接触目标数）。同一挥刀内对同一Actor（场景对象）只计一次接触；黄色叉标记接触位置，目前不扣血。

轨迹来自实际武器网格的刀根和刀尖世界坐标。粗线是刀尖路径，细线是刀根路径，细扇面线是每次采样的刀刃。红色表示命中窗口，青色表示允许躲避，绿色表示允许移动，灰色表示其余阶段；当前刀刃为黄色。轨迹每次挥刀重置，动作结束后保留两秒，并按当前相机重新投影，因此移动相机时不会固定在屏幕上。

控制台 `arpg.Debug.AttackTrace 0` 关闭此HUD和轨迹，`arpg.Debug.AttackTrace 1` 打开。原有准星参考线由独立的 `arpg.Debug.ScreenCenter 0/1` 控制。HUD文字使用引擎默认字体的英文短标签，避免中文字体缺字。

当前光剑的 Blueprint（蓝图）默认值新增 Weapon / Trace（武器/轨迹）配置：BladeBaseLocal=(0,0,20.9874)，BladeTipLocal=(0,0,122.1274)，单位厘米，位于武器网格局部空间，端点来自SaberBlade材质分区顶点范围。武器组件变换负责转换到世界空间；换武器时需提供相应刀刃端点，不能沿用手腕轨迹代替。

## 职责与清理

输入仍由MyPlayerController接收，Character只转发请求。NotifyState（通知状态）只向ASC（技能系统组件）发送开始/结束事件，不保存角色运行状态。LightAttackAbility（轻攻击技能）收到自身蒙太奇事件后持有Window.Attack.Hit、Window.Cancel.Evade、Window.Cancel.Move标签；完成、取消、中断、播放失败统一清理，避免仅依赖NotifyEnd（通知结束）导致窗口残留。

EvadeAbility（躲避技能）在攻击中检查躲避取消权限，提交成功后取消攻击再播放躲避。移动取消由独立AttackTraceComponent（攻击轨迹组件）在移动窗口中观察当前移动输入，再请求攻击技能结束；技能任务停止蒙太奇并按原有0.12秒混出，Attacking标签释放后恢复移动。混出和移动恢复同时开始。

AttackTraceComponent在骨骼姿态更新后采样，最多保存512次当前攻击数据。接触诊断只在命中窗口用沿刀刃多个位置的球扫掠检查Pawn（角色）和WorldDynamic（动态物体），忽略自己及武器。这是按运行帧采样的调试检测，低帧率下相邻姿态间使用直线扫掠，尚未实现离线姿态子采样、精确弧线、遮挡过滤或正式伤害结算。当前沿用单机权威端技能，不声明联机输入、预测与远端轨迹同步完成。

## 本轮验证

完整Development Editor（开发编辑器）编译和重新加载通过。在PIE（在编辑器中运行）内通过角色公开请求验证：完整收势1.4167秒、过期输入失效、0.3299秒缓冲躲避在0.4142秒触发、持续移动在0.6086秒取消；四种结束路径的窗口均清空。第14帧实机截图确认HUD、时间条、刀根/刀尖路径和当前刀刃对齐。测试使用临时Slate（界面框架）回调观察状态，没有新增Python脚本或持久测试代码；实际物理按键、接触目标计数/去重、极低帧率扫掠精度和联机未实测。
